# Java Backend Labs

Лабораторные по [курсу Java Backend](https://gitlab.com/VladKarandashov/java-backend-course-demo/-/tree/main/assignments), вариант 15.

- [Лабораторная 1](lab-1/README.md): файлы, коллекции и CRUD в CSV.

Команды сборки и запуска находятся в папке лабораторной. Версии зависимостей
и SpotBugs настроены в корневом `pom.xml`, CI - в `.github/workflows/github-ci.yaml`.
